# Demo Preview Data — V31.1

This update adds presentation-only sample data to data-heavy pages when Supabase returns no records.

## Important
- Sample records are **not inserted into Supabase**.
- Real Supabase records always take priority and are displayed normally.
- Demo cards are labelled **Demo Preview** and the page shows a notice explaining that the data is illustrative.
- Cart, checkout, search, product-detail not-found states, and other genuinely user-empty states are intentionally not populated with fake records.

## Updated pages
- Artisan Sales Analytics: 2-month sample revenue/order trend + top products.
- Artisan Orders: 2-month order activity chart + sample order list.
- Customer Orders: 2-month order activity chart + sample tracked orders.
- Admin Orders: 2-month order activity chart + sample platform orders.
- Admin Reports: 2-month GMV chart + sample platform metrics/top artisans.
- Admin Payments: sample transaction records when the real payment table is empty.
- Admin Returns: sample return cases when empty.
- Admin Product Moderation: sample pending-review products when empty.
- Admin Artisan Verification: sample verification queue when empty.
- Admin Users: sample users when the real profiles table is empty.
- Artisan Reviews: sample customer reviews when empty.
- Artisan Notifications: sample notifications when empty.
- Artisan Inventory: sample stock cards when the artisan has no products.
- Artisan Products: sample product cards when the artisan has no products.
- Customer Home: sample product showcase when no approved products exist.
